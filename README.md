# Прайс-страница WF Media

Одностраничник с прайсом на рекламу в сообществах ВКонтакте + админка. Без зависимостей — только Node.js.

- Сайт: https://wfmedia.uxlve.lol
- Админка: https://wfmedia.uxlve.lol/admin — вход по паролю, сохранение сразу попадает на сайт.

Никаких GitHub-токенов, коммитов и Actions: сайт и админка живут на своём сервере (Dokploy),
данные лежат в томе `/data` и переживают пересборки.

## Как это работает

- `server.js` раздаёт страницу и админку, хранит `data.json` и аватарки в `DATA_DIR`.
- Кнопка «Обновить всё из ВК» запускает обход сообществ на сервере: подписчики, охваты, аватарки.
  Обход идёт в фоне, админка ждёт результат и сама перерисовывает список.
- Тот же обход сервер делает по расписанию — раз в `REFRESH_MINUTES` минут (по умолчанию 360).
- Названия сообществ и вручную выставленный охват автообновление не трогает.
- Папка `docs/` — «заводские» данные: с них наполняется пустой том при первом запуске.
  Там же лежит оферта. Старый адрес на GitHub Pages редиректит на новый домен.

## Переменные окружения

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `ADMIN_PASSWORD` | из `config.json` | пароль от `/admin` |
| `DATA_DIR` | `docs/` | где лежат `data.json` и `avatars/` |
| `PORT` | `3000` | порт сервера |
| `REFRESH_MINUTES` | `360` | как часто обновлять данные из ВК; `0` — выключить |

## Локально

```bash
node server.js
```

- Страница: http://localhost:3000
- Админка: http://localhost:3000/admin — пароль из `config.json` (создаётся при первом запуске, по умолчанию `admin`; в репозиторий не попадает)

Локально данные пишутся прямо в `docs/`. Чтобы не трогать «заводские» — задайте свой `DATA_DIR`:

```bash
DATA_DIR=/tmp/vkpage ADMIN_PASSWORD=secret node server.js
```

## Деплой

Dokploy собирает `Dockerfile` из этого репозитория (ветка `main`) и запускает контейнер;
том `wfmedia-data` смонтирован в `/data`. Новый деплой — кнопкой Deploy в панели Dokploy;
данные в томе при этом не трогаются, пересоздаётся только контейнер.

Чтобы деплой запускался сам по пушу в `main`, в настройках репозитория на GitHub нужно
добавить вебхук на адрес деплоя из панели Dokploy (Application → Deployments → Webhook URL).
