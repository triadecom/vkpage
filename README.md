# Прайс-страница для пабликов ВК

Одностраничник с прайсом на рекламу в сообществах ВКонтакте + админка. Без зависимостей — только Node.js и GitHub.

Данные и аватарки канонически живут в `docs/` — эту папку раздаёт GitHub Pages.

## Сайт

- Страница: https://triadecom.github.io/vkpage/
- Админка онлайн: https://triadecom.github.io/vkpage/admin/ — вход по GitHub-токену с правом записи в репозиторий (на компьютере админа его печатает команда `gh auth token`). Сохранение коммитит `docs/data.json` через GitHub API, сайт обновляется сам через минуту-две.
- Кнопка «Обновить всё из ВК» в онлайн-админке запускает workflow `refresh` — он подтягивает подписчиков, охваты и аватарки.

## Автообновление из ВК (GitHub Actions)

Workflow `.github/workflows/refresh.yml` каждые 6 часов (и по кнопке) запускает `scripts/refresh.js`: обновляет подписчиков, охваты и аватарки в `docs/`, названия не трогает (кроме пустых). Название из `og:title`, аватарка из `og:image`, подписчики из JSON-LD, охват — медиана просмотров последних постов со стены.

## Локальный режим

```bash
node server.js
```

- Страница: http://localhost:3000
- Админка: http://localhost:3000/admin — вход по паролю из `config.json` (создаётся при первом запуске, по умолчанию `admin`; в репозиторий не попадает)

Локально в редакторе сообщества данные из ВК подтягиваются сразу при вставке ссылки. Кнопка «Опубликовать» собирает статику в `docs/`, делает `git pull --rebase` и `git push`. Локальный поллинг (`pollMinutes` в `config.json`) обновляет данные на диске между публикациями.

Если правили и онлайн, и локально — перед локальной работой сделайте `git pull`.
