# Прайс-страница для пабликов ВК

Одностраничник с прайсом на рекламу в сообществах ВКонтакте + админка для управления данными. Без зависимостей — только Node.js.

## Запуск

```bash
node server.js
```

- Страница: http://localhost:3000
- Админка: http://localhost:3000/admin

## Админка

Пароль лежит в `config.json` (создаётся при первом запуске, по умолчанию `admin`) — поменяйте его перед публикацией.

В админке можно менять заголовок и контакты страницы, условия размещения, добавлять/редактировать/удалять сообщества и менять их порядок. Данные сохраняются в `data.json`.

В редакторе сообщества достаточно вставить ссылку на паблик — название, аватарка, подписчики и охват подтянутся из ВК автоматически. Сервер запрашивает страницу ВК от имени краулера: название из `og:title`, аватарка из `og:image` (складываются в `public/avatars/`), подписчики из JSON-LD, охват — медиана просмотров последних постов. Если нужно своё название — поправьте его после загрузки.

Порядок сообществ на странице настраивается: вручную стрелками или автосортировка по подписчикам (настройка «Порядок сообществ»).

Сервер сам опрашивает ВК каждые `pollMinutes` минут (по умолчанию 360, задаётся в `config.json`, `0` — выключить) и обновляет в `data.json` точные подписчики, охваты и аватарки. Названия при поллинге не трогаются.

## Публикация (GitHub Pages)

Публичная страница хостится бесплатно на GitHub Pages из папки `docs/`. Рабочий цикл:

1. Запустить локально `node server.js`, внести правки в админке, нажать «Сохранить изменения».
2. Нажать **«Опубликовать»** — сервер соберёт статическую версию в `docs/` (страница + данные + аватарки) и сделает `git push`. Через минуту страница в интернете обновится.

Админка в интернет не выкладывается — она работает только локально. `config.json` с паролем в репозиторий не попадает (`.gitignore`).
